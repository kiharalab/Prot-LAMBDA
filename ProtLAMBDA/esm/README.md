# Meta ESM (Evolutionary Scale Modeling) Files

This directory contains source code files that were copied and/or adapted from the [ESM project](https://github.com/facebookresearch/esm) developed by Meta Platforms, Inc. (formerly Facebook AI Research).

## Purpose
These files are included in this repository without requiring the entire ESM package as a dependency. 

## Acknowledgment
All credit for the original design, implementation, and underlying research belongs to the Meta FAIR team. 

If you are using this repository for academic or scientific research, please ensure you cite the appropriate ESM publications (such as *Lin et al., 2022* or *Rives et al., 2021*) as requested in their [official repository](https://github.com/facebookresearch/esm).
