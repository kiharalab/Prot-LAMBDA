# OpenFold Files

This directory contains source code files that were copied and/or adapted from the [OpenFold project](https://github.com/aqlaboratory/openfold), developed by the OpenFold Consortium and the AlQuraishi Laboratory.

## Purpose
These files are included in this repository without requiring the entire OpenFold package as a dependency.
